# AI Landing Page Generator 🚀

## Project Overview

The AI Landing Page Generator is a Python-based content generation project developed during the Data Alcott Systems AI & Data Science Internship.

It generates marketing content for different landing page types using copywriting frameworks and reusable content templates.

## Features

- Headline generation using AIDA, PAS, and FAB frameworks.
- Subheadline generation.
- Benefits section templates.
- Social proof templates.
- Call-to-Action (CTA) generation.
- FAQ generation.
- Complete landing page generation.
- Conversion readiness score calculation.
- A/B headline variations.
- Testimonial templates.
- Interactive Streamlit web interface.

## Supported Landing Page Types

1. SaaS
2. E-commerce
3. Course
4. Service
5. Mobile Application

## Installation

Install the required Python libraries:

```bash
pip install pandas numpy nltk scikit-learn streamlit
```

## How to Run

1. Download or clone the project repository.
2. Open the project folder.
3. Install the required libraries.
4. Run the Streamlit application:

```bash
streamlit run app.py
```

5. Open the local URL displayed in the terminal.
